# API Application

This is the main API for the stack-2026 monorepo. Built with Fastify 5 and TypeScript 5.

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `dev` — Run with hot-reload via tsx watch
- `build` — Compile TypeScript to dist/
- `start` — Run compiled production build
- `lint` — Lint source files
- `typecheck` — Run TypeScript type checking without emitting

## Structure

- `src/` — Main source code
- `dist/` — Compiled output (after build)
